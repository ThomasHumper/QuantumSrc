Engine

A foundation built for portability.

QuantumSrc separates engine systems from platform-specific implementations, making it possible to target very different hardware without rebuilding the entire architecture.

01

Modular Rendering

Pluggable rendering backends for OpenGL, Direct3D, software rendering, and specialized console hardware.

02

Custom Asset Pipeline

Native PAF, PKD, PMF, P3M, PTF, and PTM formats connect content creation directly to the engine.

03

Legacy Hardware

Architecture designed to accommodate hardware and APIs from multiple generations.

04

Audio

Software and hardware-oriented audio paths, OpenAL integration, effects, filters, reverb, and platform audio support.

05

Input & UI

Keyboard, mouse, controllers, touch input, and a common UI layer for different targets.

06

Networking

Client/server architecture with shared engine state and dedicated server support.

Development

Simple to build.

QuantumSrc uses CMake for cross-platform configuration and can be driven by the project's Ruby orchestration script for larger build, asset, testing, and packaging workflows.

The engine is written in C++20 and keeps external dependencies modular so individual targets can enable only what they need. 

# Configure
cmake -S . -B build

# Build
cmake --build build

# Release
cmake -S . -B build \
    -DCMAKE_BUILD_TYPE=Release

cmake --build build

# Or use the project orchestrator
ruby engine.rb all
